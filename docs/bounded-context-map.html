Context Relationships

● Patient → Clinical, Billing, Scheduling — Customer-Supplier (patient identity shared via events + API)
● Clinical → Billing — Customer-Supplier (encounters trigger claims via EncounterClosed)
● Clinical ↔ Lab & Pharmacy — Partnership (bidirectional: orders out, results/Rx back)
● Clinical → CDS & Quality — Customer-Supplier (clinical data feeds rule evaluation)
● Scheduling → Clinical — Customer-Supplier (check-in triggers encounter creation)
● Identity & Org → All — Published Language / Shared Kernel (auth + reference data)
● Interop ↔ All — Anti-Corruption Layer (FHIR/CCDA translation facade)
● Billing → Organization — Conformist (billing conforms to payer/facility master data)
